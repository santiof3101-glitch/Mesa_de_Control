# Cambios 2026-10-06 (seguridad y rendimiento)

## Seguridad
- La clave de administrador ya no aparece en pantalla ni escrita en el codigo; se guarda como hash (PBKDF2-SHA256).
- Nuevo formulario "Clave de administrador" en Admin > Usuarios. Mientras se use la clave inicial aparece un aviso.
- Las claves de usuarios (comerciales, mesa de control, gerencia, datos) se guardan como hash. Las claves antiguas en texto plano se convierten solas al iniciar sesion o al guardar usuarios.
- server.js: la API local solo acepta peticiones de la propia aplicacion (http://127.0.0.1:8787), bloquea otros nombres de servidor y no sirve el archivo de datos ni los respaldos por HTTP.
- .gitignore para no subir datos ni respaldos.

## Estabilidad de datos
- server.js: lectura correcta de tildes y eñes en guardados grandes.
- server.js: escritura atomica del archivo de datos (no queda a medias si se apaga el PC).
- Respaldos: automatico cada 15 minutos (ultimos 96), uno diario por 60 dias y manuales aparte (ultimos 40).
- iniciar-autocor.bat abre http://127.0.0.1:8787; si se abre index.html directo y el servidor esta activo, redirige solo.

## Rendimiento
- Las librerias PDF y plantillas de consignacion (~3,5 MB) se cargan solo cuando se necesitan.
- Imagenes hero convertidas a WebP (de ~9 MB a ~0,5 MB). Eliminadas 2 imagenes sin uso.
- Version de la app alineada entre index.html y app.js (antes provocaba una recarga extra en cada visita).

## Limpieza
- Eliminadas 4 funciones duplicadas en app.js que nunca se ejecutaban.
